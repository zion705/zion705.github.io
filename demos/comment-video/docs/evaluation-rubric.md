# 评论→商品回复视频评测量表

版本：`1.0`  
目标：判断一支视频是否真正降低了评论对应的购买阻力，同时不牺牲商品真实性、安全与用户信任。

## 1. 总分与放行规则

六个维度按100分分别打分，再加权：

```text
总分 =
评论相关性 × 20%
+ 事实一致性 × 25%
+ 口播自然度 × 15%
+ 证据覆盖 × 15%
+ 前3秒张力 × 15%
+ 转化感 × 10%
```

放行标准：

| 结果 | 条件 | 处理 |
|---|---|---|
| 自动通过 | 总分≥85，事实一致性≥90，证据覆盖≥80，无一票否决 | 可进入人工终审与导出 |
| 人工复核 | 总分75—84，或高风险品类 | 编辑/合规逐句复核 |
| 自动重写 | 总分<75，且问题来自脚本或素材匹配 | 按最低分维度定向重写 |
| 直接拒绝 | 触发任一一票否决 | 不允许被高总分覆盖 |

模型自评分只能用于初筛；事实ID、素材ID、时间线和加权总分必须由程序重新校验。最终发布仍由人负责。

## 2. 六维评分

每个维度先按1—5级打锚点分，再换算为百分制：`1=20，2=40，3=60，4=80，5=100`。允许评审员在锚点之间给10分增量。

### 2.1 评论相关性（20%）

**定义**：视频是否从头到尾回答原评论背后的核心购买阻力，而不是把评论当作通用广告的开场贴纸。

| 等级 | 评判锚点 |
|---|---|
| 5 | 保留评论核心语义；明确识别购买阻力；每一段都推动回答；结尾给出相应判断方法。 |
| 4 | 回答主要问题，存在少量无关卖点，但不影响理解。 |
| 3 | 提到评论问题，但主体仍是通用产品介绍。 |
| 2 | 歪曲、弱化评论，挑了更容易回答的部分。 |
| 1 | 只展示评论卡，后续内容与评论无关。 |

**检查问题**

- 去掉评论卡后，口播还能看出它具体在回答什么吗？
- 评论中的限定条件（梨形、喷完就擦、是否必要）是否被保留？
- CTA是否继续解决同一个问题？

### 2.2 事实一致性（25%）

**定义**：参数、材质、效果、实验、适用范围和安全表达是否完全来自事实白名单，且没有越过证据边界。

| 等级 | 评判锚点 |
|---|---|
| 5 | 所有可验证主张均绑定有效`factId`；措辞不超过原事实；未知项仍为未知；免责声明完整。 |
| 4 | 核心主张有依据，存在不改变购买判断的轻微措辞扩大。 |
| 3 | 参数基本正确，但有一项效果或适用性缺少直接依据，需改写。 |
| 2 | 多个结论由常识或素材标签推断，事实来源不清。 |
| 1 | 虚构参数/功效，篡改实验结论，或与商品事实矛盾。 |

**强制要求**

- 任何数字、百分比、次数、时长、成分、材质都必须有`factId`；
- “可见残留更少”不能改成“清洁率更高”；
- 个体试穿不能改成“适合所有梨形身材”；
- 纹理板实验不能外推为人体或健康结论。

### 2.3 口播自然度（15%）

**定义**：文案是否像真实商家/达人面对一条评论说话，是否便于TTS或真人一口气讲完。

| 等级 | 评判锚点 |
|---|---|
| 5 | 短句、有停顿和态度转折；听得懂、说得出口；没有AI套话和参数堆砌。 |
| 4 | 整体口语化，个别句子略长或略像说明书。 |
| 3 | 信息清楚但节奏平，连续罗列卖点或安全提示。 |
| 2 | 大量“首先其次”“综上所述”、营销黑话或生硬翻译腔。 |
| 1 | 难以口播、语义不通、角色语气前后矛盾。 |

**建议测法**

- 以正常中文口播速度试读，是否在目标时长内且无需抢词；
- 单句尽量不超过28个汉字，长参数句允许拆分；
- 删除“事实上、值得一提的是、总而言之”等AI连接词后是否更顺。

### 2.4 证据覆盖（15%）

**定义**：影响购买判断的关键结论是否在画面中得到可见、可核验的支持。

| 等级 | 评判锚点 |
|---|---|
| 5 | 每个关键主张均有对应素材；证据条件清楚；脚本、素材和字幕一致；没有用生成画面伪造效果。 |
| 4 | 核心主张都有素材，次要信息只由口播或包装支持。 |
| 3 | 有展示但证据链不完整，如只有结果没有同条件过程。 |
| 2 | 大部分是达人口播、产品空镜或不相关场景素材。 |
| 1 | 画面与口播矛盾，或用AI生成商品效果充当真实证据。 |

**Evidence Coverage计算建议**

```text
证据覆盖率 =
有有效素材支持的关键Claim权重之和
/ 全部关键Claim权重之和
```

成交关键Claim权重为2，辅助Claim权重为1。覆盖率低于80%不得自动放行。

### 2.5 前3秒张力（15%）

**定义**：用户是否能在前三秒看懂冲突、知道视频会如何回答，并产生继续观看的理由。

| 等级 | 评判锚点 |
|---|---|
| 5 | 评论冲突清楚；达人有克制的态度转折；立即承诺“看实测/看两组/改一个变量”。 |
| 4 | 问题明确且表达自然，但证明方式到3—5秒才出现。 |
| 3 | 展示评论并复述，缺少态度或证据预告。 |
| 2 | 慢自我介绍、铺垫品牌背景，用户3秒内不知道要回答什么。 |
| 1 | 靠辱骂、夸张惊吓、虚假结果或无关视觉吸引注意。 |

**不是张力的东西**

- 放大音量、连续感叹号；
- 把温和评论改写成恶意攻击；
- “震惊！所有人都被骗了”式虚假冲突；
- 生成模型无法稳定完成的复杂动作。

### 2.6 转化感（10%）

**定义**：视频是否把被说服的用户送到合理的下一步，同时保持可信度。

| 等级 | 评判锚点 |
|---|---|
| 5 | CTA与评论阻力高度一致；动作具体；用户知道点击后能获得什么；不过度催促。 |
| 4 | CTA基本相关，但表达略通用。 |
| 3 | 有商品卡引导，但没有说明为什么现在要点。 |
| 2 | 突然“赶紧抢”“最后一天”，与前文无关。 |
| 1 | 虚假稀缺、诱导承诺或完全没有下一步。 |

**阻力—CTA映射**

| 评论阻力 | 推荐CTA |
|---|---|
| 身材/尺码适配 | 看相近身材试穿、打开尺码助手、咨询腰臀围 |
| 使用方式误解 | 查看三步教程、上传问题照片、联系售后 |
| 品类必要性质疑 | 查看配方/尺寸/实验证明，自行判断适用场景 |
| 材质/参数质疑 | 打开检测报告、参数对比、细节实拍 |
| 价格质疑 | 查看单次成本或耐用周期；前提是有事实支持 |

## 3. 一票否决项

触发任意一项，`passed=false`，不计算“高分抵消”。

### A. 商品真实性

- 虚构或篡改商品参数、材质、价格、优惠、认证、销量、评价数量；
- 把商家愿望、模型常识或文件名当成商品事实；
- 将个案或单次实验外推为普遍功效；
- 使用生成式视频改变商品外观、试穿结果、污渍程度或实验结果，却当作实拍证据；
- 评论是模拟/改写的，却伪装成真实消费者原话对外发布。

### B. 健康与安全

- 未经证实的医疗、治疗、抗菌、防病、无副作用等宣称；
- 演示危险使用方式，或删除决定安全的通风、防护、禁配和禁用表面提示；
- 鼓励敏感人群直接使用而不保留输入中的谨慎边界；
- 清洁剂与其他化学品混用、喷向人体或在密闭空间危险演示。

### C. 用户与社会风险

- 辱骂、羞辱或煽动围攻评论者；
- 身材羞辱、疾病羞辱、性别/地域/年龄歧视；
- 暴露评论者头像、昵称、订单、地址等个人信息；
- 为制造戏剧性歪曲用户原意，或把真实质量问题说成“用户不会用”。

### D. 证据与剪辑完整性

- 口播数字与包装、字幕或实拍画面不一致；
- A/B对照的关键条件不同，却声称只有一个变量；
- 素材版权状态不是“已授权”；
- 评论卡、免责声明或关键安全字幕出现乱码/被裁切/停留短到无法阅读；
- 总时长、脚本和分镜时间线断裂，导致重要边界在导出时被截掉。

## 4. 评测流程

### Gate 0：输入资格

1. 评论是否有代表性或明确业务价值？
2. 是否有可回答的商家事实？
3. 是否有最少一条可见证据？
4. 是否包含隐私、事故或需一对一处理的信息？

不满足2或3时，输出“待补事实/待补拍”，不进入生成。

### Gate 1：机器规则

- JSON Schema合法；
- 时间线连续；
- `factId`与`assetId`均存在；
- 数字Claim绑定事实；
- 素材版权为可用；
- CTA action在产品允许列表；
- 敏感词与绝对词扫描。

### Gate 2：独立模型评审

评审模型不能看到生成模型的自我解释，只看：

- 原评论与商家意图；
- 商品事实白名单与未知项；
- 输出脚本、分镜、素材匹配；
- 六维量表与一票否决项。

要求它返回逐句Claim Ledger、六维分数和最小修改建议。

### Gate 3：人工终审

高风险、正式投放、付费素材、健康安全类内容必须人工终审。终审员重点查看：

- 评论是否被公平呈现；
- 商品与实验画面有没有被剪辑误导；
- 免责声明是否可见、可听；
- CTA是否符合平台规则和商家实际能力。

### Gate 4：上线数据闭环

离线高分不等于商业有效。上线后记录：

- 3秒留存率、完播率；
- 评论区相同疑问的新增/下降趋势；
- 商品卡点击率、加购率、成交率；
- 负向评论率、隐藏/举报率；
- 使用误解类问题的售后咨询与退款率。

当“留存提升但负向评论或退款上升”时，不判定为成功；优先复核是否用了过度冲突或扩大承诺。
